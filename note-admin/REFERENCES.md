## 使い方
- 新しい記事を書く前に、アクセスできる参考元の新着を確認して、テーマや切り口のヒントを探す。
- 心理学の研究（実在する論文）で裏づけて、ぽこさんの言葉（サメモード／イルカモード）で書き直す。
- 医療に関わる内容は、診断と受け取られる書き方をせず、受診の目安を添える（11・12で確認）。
- memo欄に「何を参考にしたか」「パクリ回避のために変えた点」を書く。

## 記事の型（現在の基準）
こんにちは＋臨床心理士・公認心理師のぽこです → つかみ → 「結論から言うと、〜。今日は、そんなお話です。」 → 「こんな方に読んでほしい記事です。」✅3つ（つかみ・よく届く声と同じ内容にしない） → よく届く声（プライバシーの注意書き） → サメモードの一文 → 本文（研究＋自分の言葉） → 今日のワーク＋実例 → 今日のまとめ✅（結論と同じ文にしない） → 締めのひとこと → --- → 相談への一文 → 講座の章案内・次回予告・雑談会 → mosh → よくある質問・ご感想 → モード診断（テーマ別） → 参考文献
- タイトル：「〇〇な人へ｜得られる変化＋数字」
- 本文（相談リンクより前）：空白を除いて3,000字以上
- 同じ文・同じ言い回しを、つかみ・結論・チェックリスト・よく届く声・まとめ・実例でくり返さない
