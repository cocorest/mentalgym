## 2. 第1回 要約から抜き取った内容
**テーマ: 平日外泊も解禁。モラハラ気質の夫から応援されるようになった秘密**

### 講師の実体験（導入）
- 以前は電動自転車を買うことすら夫に反対されていた
- 今は月に外泊3回、月末には子どもを夫に預けてドバイへ約5日間
- 夫は何を提案しても否定から入る人だった（「それ必要なの？」「高くない？」「なんで行くの？」）
- 2年かけて関係が大きく変わった

### ポイント1: 「行ってもいい？」と聞くから上下関係になる
- 「何て言えば許してもらえるか」「嫌な顔されないか」と考えている時点で、相手を**許可する側**、自分を**許可される側**にしている
- 相手の機嫌を損ねないことばかり考えるコミュニケーションは、実は魅力的ではない

### ポイント2: 許可取りではなく「ビジョンの共有」をする
- 普段から「私はこういう人生を送りたい」「こういう時間があると幸せ」「友達と過ごす時間があるから育児も楽しく頑張れる」と伝えておく
- 外泊直前に説得するのではなく、**普段から「私が何をすると幸せになるのか」を伝えておく**
- すると「彼女が幸せになるために必要なこと」として理解してもらいやすい

### ポイント3: 喜びだけでなく「悲しみ」も伝える（この回の最重要ポイント）
- 「いつも私ばかり家事育児してるんだから外泊くらいいいでしょ」と正論で戦いたくなる（講師もよくやる）
- 責めるより、「こういう時間がないと私はしんどい」「この状態が続くと悲しくなる」と自分の感情を伝える
- **「あなたのせいで悲しい」ではなく「私はこういう状態だと悲しい」**
- 講師は夫と今後の関係を話し合ったとき、自分の悲しみや過去の経験まで伝えたことで、夫の考え方が変わった

### ポイント4: 叶えてもらったら喜びを全力で伝える
- 帰ってきたら「めっちゃ楽しかった！」「すごくリフレッシュできた！」と伝える
- 相手は「自分が協力したことでこんなに喜んでもらえた」と感じられる
- お願いして終わりではなく、喜びまで共有することが「応援される関係」を育てる

### 今日いちばん伝えたかったこと
- 「嫌われないためのコミュニケーション」では関係は深まらない
- 顔色をうかがうことと、大切にされることは違う
- 欲しかったのは外泊の許可ではなく、**「楽しんできてね！」と応援してもらえる関係**
- 夫婦だけでなく恋愛も同じ。「この子しかいない」と思われる関係は見た目だけでは作れない。**愛されるためのコミュニケーション**が作る
- 感情を隠して嫌われないように生きるのではなく、感情を伝えてもっと愛される
- 講師は「非モテ歴20年以上」

## 3. 第2回 要約から抜き取った内容
**テーマ: メンヘラ上等！どんなに切れ散らかしても好かれる女の怒り方**（11/12（木）15:00〜）

### 講師の実体験（導入）
- 怒ると「嫌われるかも」「関係が悪くなるかも」と飲み込みがち
- 講師はもともと「とってもメンヘラ」。二股した元彼の家の郵便受けにオレンジジュースをかけて警察沙汰に（警察には「あんな彼氏やめときな」と逆に説得された）
- 夫と大ゲンカした夜、スーツ・靴・カバンを玄関の外に投げ、夫ごと追い出したことも
- それでも夫とは元に戻れるし関係も悪くならない（夫いわく「スーツとカバンはOK、投げるなら仕事用の靴にして」）
- **可愛く怒るのは無理。無理なことは無理にやらなくていい。大事なのは「ちゃんと怒っても許される関係性」を作ること**

### ポイント1: 怒らないのは「都合のいい相手」の一歩手前
- 怒らない相手は男性にとって楽で安心。癒しの場であることも大事
- でも嫌なことや違和感まで飲み込んでいると、**「都合のいい相手」の一歩手前**
- 長く一緒にいるほど相手は気を使わなくなる。我慢を続けると「これでいいんだ」と思われ、気持ちを汲んでもらえない関係になる
- 男性は感情を読み取るのが苦手。だから**「私はこれが嫌です」とわかりやすく伝える**
- おすすめは**小さな違和感のうちに**「ちょっとそれ、嫌かも」くらいの温度で言うこと（まだ爆発していないので穏やかに言える）

### ポイント2: 怒りは相手の心をいちばん強く動かす
- 喜怒哀楽の中で、怒りは相手の感情を強く動かす（SNSのケンカ動画をつい見てしまうのと同じ）
- お店でも「なんでもいいです」と言う人より、意見を言う人の方が丁寧に扱われることがある
- **感情を動かされた相手を、人は無視できない**
- 大切なパートナーにこそ怒りを見せていい。相手にちょっとストレスがかかってもいい（「私と付き合った人はだいたい一回肌荒れします」）。パートナーなのだから受け止めてもらっていい

### ポイント3: モヤモヤの怒りと、言葉にできる怒りは分けて扱う
- 怒りが湧いたら、自分が「ただモヤモヤしている」のか「理由を言葉にできる」のかを見る
- **言葉にできないまま切れ散らかすのはリスクが高い**（男性には「何言ってるかわからない」「ただ怒ってるだけ」に見える）
- 講師が本気で戦うのは、理由を説明できるときだけ
- 正論でなくていい。**どっちが正しいかではなく「私が悲しい」。それが全て**
- モヤモヤのときは、その場で軽く伝える（「なんかちょっと悲しいかも」「言葉にできないけど、嫌だったかも」）
- 男性は後から言われると「今さら？」となりがち。だから**言葉にできなくても「今、悲しい」だけはその場で伝え、なぜ悲しいのかを一緒に考える**
- それでも向き合ってくれないなら「悲しいって言ってるのに、なんで向き合ってくれないの？」と、その態度に怒っていい

### ポイント4: ベースは「あなたと仲良くいたいから怒ってる」
- 口調や態度は怒っていても、奥にあるのは「あなたと仲良くいたいから、この悲しみを無視できない」
- 責めたいのではなく仲良くいたいから向き合っている。この気持ちが土台にあると、激しいケンカでも後で回収しやすい
- ケンカの後は、ケンカをネタに笑い合う／相手にとって「学びの時間」だったと思ってもらう
- 男性は自分の感情と向き合わずに生きてきた人が多い。ケンカを通して「自分はこういうときにこういう気持ちになるんだ」と気づければ学びになる
- 講師が言われた言葉:「今までこんなに向き合ってもらったことがなかった。自分のことをよく理解できたから、このケンカにはすごく意味があった」→ **そう思ってもらえたら勝ち**

### 今日いちばん伝えたかったこと
- **大前提: 切れ散らかしても大丈夫なのは「人間として好かれている」とき**
- 好きでない人から怒られたらうざいだけ。大切な人が怒っていたら「どうしたの？」と向き合える
- 「顔が好き」「タイミングが合った」程度で始まった関係は、ケンカで「別にいいや」と手放される
- だから**「この子のことが人間として大切」と思われる関係を育て続ける**。人間関係は一度作ったら終わりではなく、育み合うもの
- 土台があれば、怒っても戻れる／悲しいと言えば聞いてもらえる／行きたい場所にも行ける
- 怒ることは「私はこれが嫌だよ」と教える**自己紹介であり、愛**でもある
- 我慢して突然離れるより、気持ちを共有しながら関係を育てる方が絶対にずれない

## 4. パートナーシップ講座への活かし方（メンタルジム流に置き換え）

元講座の主張は、あなたの専門（ACT・自己慈悲・NVC）でそのまま説明できます。根拠を添えると、体験談ベースの元講座より信頼性で差がつきます。

| 元講座の主張 | メンタルジムでの言い換え・裏づけ |
|---|---|
| 許可取りは上下関係を作る | 「お願い」と「要求」の違い（NVC）。相手の反応を変えようとするより、自分の願いを明確にする |
| 普段からビジョンを共有 | 価値の明確化（ACT）。「何を大切に生きたいか」を言葉にして共有しておく |
| 「あなたのせいで」ではなく「私は悲しい」 | アイメッセージ／NVCの「観察・感情・ニーズ・リクエスト」 |
| 叶えてもらったら喜びを伝える | 感謝の伝え方・ポジティブな関わりの比率を上げる |
| 小さな違和感のうちに言う | 感情に早めに気づく練習（マインドフルネス）。爆発する前に「ちょっと嫌かも」 |
| モヤモヤと言葉にできる怒りを分ける | 事実と思考の切り離し（脱フュージョン）。怒りの下にある一次感情（悲しみ・不安）に気づく |
| 「仲良くいたいから怒る」 | 怒りの奥のニーズ（つながり・尊重）を伝える |
| ケンカは学びの時間 | 修復の会話。衝突は関係を深める機会 |
| 「人間として好かれている」土台を育て続ける | 心理的安全性のある関係を日々育てる |

**注意したい点**: 元講座は「男性は感情を読むのが苦手」など性別で一般化した言い方や、物を投げるなど激しい行動を肯定的に語っています。臨床心理士監修の講座としては、性別を問わない言い方にし、物を投げる・追い出すなどの行動は勧めない形にした方が安全です。
