# 収益設計書：「見られて稼ぐ」×「売って稼ぐ」

作成日：2026-10-08 ／ 前提の数字は `00_SNS現状把握.md`（X 3,867／Facebook 2,270／note 1,514／Instagram 520／Threads 104）

> **各SNSの収益化の条件は、ここ2か月で大きく変わりました。**
> - Xは2026年9月7日に旧制度を終了し、新制度に切り替わりました。
> - YouTubeは2027年2月1日から条件が約2倍になります。
>
> 下の条件は2026年10月時点の公開情報（二次情報を含む）です。申請前に、各アプリの収益化画面と公式ヘルプで必ず確認してください。

## 1. 全体像：収入のエンジンは2つ

```
 ┌───────────── エンジンA：見られて稼ぐ（アテンション収益）──────────────┐
 │  X 新報酬制度 / Facebook 収益化 / Instagram ギフト / YouTube 広告           │
 │  ＋ ぽ子さんがすでに持っている「読まれた分だけ入る」収入                       │
 │    Kindle Unlimited の既読ページ / Audible / note 有料記事・メンバーシップ   │
 │    / Amazonアソシエイト                                                     │
 └──────────────────────────────┬──────────────────────────────┘
                                │ 同じ投稿で両方を狙う
 ┌───────────── エンジンB：売って稼ぐ（商品販売）────────────────────┐
 │  SNS → LINE → 診断・セミナー → 個別作戦会議 → 6回コース／マスターコース   │
 │  ＋ 企業研修（6回講座 13万円）／講演（自治体・学校・塾）                     │
 └─────────────────────────────────────────────────────┘
```

### 大事な考え方（先に結論）
1. **SNSの「表示回数に応じたお金」は、条件に届くまで時間がかかり、届いても金額は大きくなりにくいです。** Xは支払いの計算方法を公表していないため、金額の見込みは立てられません。
2. 一方で、ぽ子さんは**すでに「読まれた分だけお金になる」商品を持っています**（Kindle Unlimited・Audible・note・Amazonアソシエイト）。**エンジンAは、SNSの収益化よりもまずこちらを太らせる**のが近道です。
3. **売上の柱はエンジンB**です。6回コース1件（¥165,000）は、SNSの表示収益の何か月分にもなる可能性が高いです。
4. それでも、**表示回数を伸ばす投稿＝商品の認知を広げる投稿**なので、2つは同じ投稿で同時に狙えます。ただし「反応を取るためだけの投稿」（炎上・あおり・釣り）は、心理職としての信頼を落とすうえに、Xの新制度でも報酬の対象外です。**やりません。**

## 2. エンジンA：媒体ごとの収益化の条件と、ぽ子さんの現在地

### 2-1. X（いちばん可能性がある）
**新制度「Original Content Rewards」（2026年9月8日〜申請受付）**
| 条件 | 内容 | ぽ子さんの現状 |
|---|---|---|
| 有料プラン | X Premium 以上 | ✅ 認証バッジあり（加入済みと思われる） |
| 認証済みフォロワー | **500人以上** | ❓ 要確認（フォロワー3,867人のうち、青バッジの人数） |
| 表示回数 | **直近90日で、認証ユーザーのホームタイムラインでの表示が50万回以上**（返信欄の表示は含まない／投稿が画面に50%以上映ったものだけ） | ❌ 推定では大きく不足。直近の投稿は1本あたり表示118〜722回 |
| その他 | 18歳以上、規約違反なし、**オリジナルの投稿のみ**（転載・自動投稿・コミュニティノートが付いた投稿は対象外） | ✅ |

- **必要な量の目安**：50万回 ÷ 90日 ＝ **1日あたり約5,600回**（しかも有料会員に見られた分だけ）。
- 今の伸び方だと条件まで距離があります。**2027年3月までの中期目標**として扱います。
- **確認してほしいこと**：Xの「収益化」画面に表示される「認証済みフォロワー数」と「直近90日の表示回数」

**条件に近づくための投稿ルール（ブランドを壊さないやり方）**
1. **1日3投稿のうち1本は「保存・引用されるサメイルカ投稿」**にする。図解か、5行以内の言い換え（サメ語→イルカ語）
2. **長文投稿**（Premiumで書ける長いポスト）を週2本。最後まで読まれる長文はタイムラインで表示が伸びやすく、そのまま note への入口にもなる
3. 受験・育児・管理職といった**その日の話題に、臨床心理士として一言**添える（引用ポストの形で）
4. 同じ分野の認証アカウントと日常的に交流する（返信欄は表示回数には数えられないが、関係づくりとフォローにつながる）
5. **やらないこと**：インプレッションを稼ぐための釣り投稿、他人の投稿の転載、自動投稿ツール

### 2-2. Facebook（すぐ確認できる）
- 収益化は**招待制・条件非公開**で、日本ではリールの収益化に対応していない、という情報が多いです。
- ぽ子さんは**認証済み＋プロフェッショナルモード（ダッシュボードあり）**なので、まず**「ダッシュボード → 収益化」に何が表示されるか**を確認してください（スター、サブスクリプションなど）。
- 表示されなくても、Facebookは**知り合い・専門職・保護者のつながりが強い場所**です。エンジンB（セミナー・講演・企業研修の紹介）の主力として使います。

### 2-3. Instagram
- **ギフト**（リールに視聴者がお金を贈れる機能）：18歳以上・プロアカウントが条件。フォロワー数の条件は「500人以上」と「5,000人以上」で情報が分かれています（ぽ子さんは520人）。プロアカウントに切り替えて、設定に「ギフト」が出るか確認してください。
- **サブスクリプション**：フォロワー1万人以上が目安。今は対象外です。
- **結論**：Instagramでの直接の収益はおまけ程度。**ママ層への認知 → LINE**（すでにプロフィールがLINEにつながっている）が本来の役割です。

### 2-4. Threads
- 日本では**直接の収益化はありません**。アメリカで試験的に行われていたボーナスも2025年4月に終わったと報じられています。
- **役割は「無料で広く届く場所」**。毎日の note から1〜3行を切り出して投稿し、Instagram経由でLINEへ流します。

### 2-5. YouTube（2027年〜の資産）
| 段階 | 今の条件（2026年） | 2027年2月1日から |
|---|---|---|
| ファンからの収益（メンバーシップ・スーパーチャット等） | 登録者500人＋直近90日に3本以上公開＋（年間3,000時間 または ショート90日300万回） | （発表を確認） |
| 広告収益 | 登録者1,000人＋（年間4,000時間 または ショート90日1,000万回） | **登録者1,000人＋（年間8,000時間 または ショート90日2,000万回）** |

- 心理学の解説は**長い動画（10〜20分）**のほうが向いています。ショートで数千万回再生を狙うのは現実的ではありません。
- 戦略：**ショートは入口（Instagramのリールをそのまま転用）、長い動画で再生時間を稼ぐ**。テーマは「受験期の親の声かけ」「怒りの仕組み」など、検索される悩みにする。
- 本格的に始めるのは2027年1月から（Kindleの第3弾・セミナー録画を素材にする）。

### 2-6. ✅ すでに持っている「読まれた分だけ入る」収入（ここを先に太らせる）

## 3. note メンバーシップ「サメイルカ部」の設計（エンジンAとBの橋渡し）

**なぜ作るか**：毎日の無料記事を読んでくれる1,514人のうち、もっと深く知りたい人に「月980円」の居場所を用意します。6回コース（¥165,000）はいきなりだと高いので、**その手前の小さな一歩**になります。

| 項目 | 内容 |
|---|---|
| 名前 | サメイルカ部（ぽ子のイルカ練習室） |
| 価格 | **月980円**（30人で月約2.5万円の手取り） |
| 毎週の中身 | ①会員限定記事1本（事例の深掘り・研究の解説）②「今週のサメ語→イルカ語」相談（掲示板で質問 → 記事で回答）③月1回 Zoom 30分の練習会（録画あり） |
| 特典 | 6回コース・マスターコースの**先行案内と会員割引**、セミナーの優先参加 |
| 無料記事との分け方 | 毎日の記事は**無料のまま**（入口を狭めない）。最後の数行だけ「続きは部員向け」にする日を週1回つくる |
| 開始時期 | **11月**（10/19セミナーの後。参加者の「もっと知りたい」の受け皿にする） |

## 5. 収入の見込み（試算）

> いずれも**仮の数字**です。表示回数による収益はXが計算方法を公表していないため、0円として計算しています。LINE公式の数字が分かったら、実際の数字で直します。

| 収入源 | 12月（3か月目）の目安 | 2027年3月（6か月目）の目安 | 計算の前提 |
|---|---|---|---|
| 6回コース（受験期プラン含む） | 2件 → ¥330,000 | 3件 → ¥495,000 | 個別作戦会議の25%が申込 |
| 個別スポット相談 | 5件 → ¥40,000 | 8件 → ¥64,000 | |
| 企業研修 | 1社 → ¥130,000 | 1社 → ¥130,000 | X・Facebookの人事・管理職層から |
| サメイルカ部（note） | 20人 → 手取り約¥16,000 | 50人 → 手取り約¥41,000 | 月980円・手数料約15%で計算 |
| note 有料記事 | ¥10,000 | ¥20,000 | 週1本・1本あたり数部 |
| Kindle・Audible・アソシエイト | KDPレポートで確認 | 第3弾の発売で増える見込み | |
| X 表示収益 | 0円（条件の準備期間） | 条件に届けば加算 | |
| **合計（目安）** | **約¥526,000** | **約¥750,000** | |

**月の時間配分の目安（ワーママ前提・1日60〜90分）**
- note の毎日の記事：別セッションで下書き → 確認15分
- Threads の切り出し：5分／X の投稿：15分／Instagram：週2回30分
- LINE の返信・個別作戦会議：週3〜4時間
- 週末にまとめて：翌週の予約投稿（60分）
