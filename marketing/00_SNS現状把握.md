## A. なぜ直接見られないのか
この作業環境は、ネットワーク設定で note.com・instagram.com・threads.com・x.com・facebook.com・lin.ee・amazon.co.jp への接続が止められています（接続すると 403 が返ってきます）。
また、**フォロワー数の推移・投稿ごとの反応・LINE友だち数・ブロック率**といった数字は、設定を開けても**ログインしないと誰にも見えません**。
そのため、次の3つの経路を組み合わせて、全部の現状を把握します。

| 経路 | 見えるもの | 状態 |
|---|---|---|
| ① 検索エンジン・Gmail・Googleドライブ | 公開されている記事・投稿の一部、通知メール、著書、講座資料 | **実施済み**（下の B） |
| ② ご本人が「データの書き出し」とスクリーンショットをドライブに置く | フォロワー数・投稿ごとの反応・LINEの数字など全部 | **ここをお願いしたい**（下の C） |
| ③ 作業環境のネットワーク設定で note.com などを許可する | note の全記事一覧とスキ数（note は公開APIがあるので取得可能） | 任意（下の D） |

## D.（任意）作業環境のネットワーク設定で note などを許可する
Claude Code のセッション画面上部の **クラウド環境メニュー → 編集 → ネットワークアクセス** で、
「Allowed domains（許可するドメイン）」に次を追加すると、こちらから直接読み込めるようになります（「Allow package managers」のチェックは付けたままにしてください）。

```
note.com
assets.st-note.com
lin.ee
page.line.me
```

note は公開APIがあるため、**全記事のタイトル・公開日・スキ数・有料か無料か**を一覧にできます。
Instagram・Threads・X・Facebook は、許可してもログインしないと中身がほとんど返ってこないため、**C の方法が確実**です。
手順の詳細：https://code.claude.com/docs/en/cloud-environments#network-access

## E. 届いたら、こちらでやること
1. 媒体ごとに **フォロワー数・直近90日の投稿数・平均反応率・反応トップ10投稿** の表を作る
2. 反応がよかった投稿の共通点（テーマ・形式・時間帯）を分析 → **「ぽ子さんの勝ちパターン」** を言葉にする
3. フォロワーの層（年齢・地域・ママ層の割合）と、受験ママ向けの方向性がずれていないか確認する
4. 戦略書（01）の目標の数字を実際の数字に合わせて直し、各媒体の役割・投稿頻度を調整する
5. 名前・ID・プロフィールの統一案を、媒体ごとにそのままコピペできる形で出す
