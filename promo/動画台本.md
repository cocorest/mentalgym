## ② はじめかたガイド動画（横型・約2分30秒）
購入者さん向け。YouTube の限定公開や、購入者ページに置く想定です。

| 時間 | 画面 | ナレーション（読み上げ用） |
|---|---|---|
| 0〜6秒 | タイトル | ぽこAIカンパニーへようこそ。このガイドでは、約30分であなた専用のAI会社をオープンします。 |
| 6〜14秒 | 用意するもの | 用意するものは3つ。パソコン、Claudeの有料プラン、そしてこのキットのZIPファイルです。 |
| 14〜22秒 | いらないもの | ターミナルの操作や、GitHubの登録、プログラミングの知識はいりません。Claudeのアプリを入れるだけで使えますよ。 |
| 22〜32秒 | STEP1 | まず、claude.ai からデスクトップアプリをダウンロードしてインストールし、ご自身のアカウントでログインします。 |
| 32〜43秒 | STEP2 | 次に、ZIPファイルを展開します。できた「poko-ai-company」フォルダは、「書類」など、わかりやすい場所に移しておきましょう。 |
| 43〜54秒 | STEP3 | Claudeアプリの画面上にある「Code」タブを押して、「Local」を選び、「Select folder」から「poko-ai-company」をフォルダごと選びます。 |
| 54〜69秒 | STEP4 | チャットに「はじめまして」と送ってみましょう。秘書のぽこが、ひとつずつ質問してくれます。わからないところは「とばす」でOK。最後にメニューが出たら準備完了です。 |
| 69〜81秒 | STEP5 | もっと便利に使うなら、入力欄の横の「＋」から「Connectors」を開いて、Gmail と Google カレンダーをつなぎましょう。つながなくても、アラームはカレンダー用のファイルで受け取れます。 |
| 81〜95秒 | 話しかけてみよう | 使い方はかんたん。ふだんの言葉で話しかけるだけです。「メニュー」と送れば、できることが全部見られます。 |
| 95〜107秒 | オフィス画面 | office フォルダの index.html をダブルクリックすると、AI社員の働くようすが見られます。「オフィスの色を変えて」と頼めば、模様替えもできますよ。 |
| 107〜120秒 | 引っかかったら① スクショ | 引っかかったときは、困っている画面のスクリーンショットを撮って、入力欄に貼りつけて「この画面になりました」と送ってください。専門用語がわからなくても大丈夫です。 |
| 120〜131秒 | 引っかかったら② 文章 | 文章で聞くときは、やろうとしたこと、起きたこと、どうしたいかの3つを書くと、答えが早くなります。Codeタブが開けないときは、Chatタブで聞いてくださいね。 |
| 131〜143秒 | こんなときは | 「許可しますか？」と聞かれたら、内容を見てOKなら許可してください。「Git is required」と表示されたら、アプリを最新版に更新すれば解決します。 |
| 143〜150秒 | おつかれさまでした | 準備おつかれさまでした。さっそく「おはよう」と話しかけてみてくださいね。 |

### 実際の画面を録画して差しかえるとよいところ
動画の中のアプリ画面は「イメージ」です。購入者さんがもっと迷わないように、次の場面はご自身のパソコンで画面録画して差しかえるのがおすすめです。
- STEP1：Claude のダウンロードページとログイン画面
- STEP3：Claude Code でフォルダを選ぶ画面
- STEP4：実際に「はじめまして」と送ったときのやりとり
- STEP5：入力欄の「＋」→「Connectors」の画面
- 引っかかったら①：実際にスクショを貼って質問するところ
