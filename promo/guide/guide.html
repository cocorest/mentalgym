STEP 1

Claude アプリを入れる

  1. claude.ai から、デスクトップアプリをダウンロードします。
  2. インストールして、アプリを開きます。
    Mac：「アプリケーション」フォルダから ／ Windows：スタートメニューから
  3. ご自身の Claude アカウントでログインします。
STEP 2

フォルダを置く

  1. ダウンロードしたZIPファイルを展開します。
    Mac：ダブルクリック ／ Windows：右クリック →「すべて展開」
  2. できた poko-ai-company フォルダを、「書類」フォルダに移します。
⚠️ デスクトップや「ダウンロード」に置きっぱなしにすると、片付けのときにうっかり消してしまうことがあります。「書類」など、わかりやすい場所に置きましょう。
置き場所は
わかりやすく♪

4

STEP 3

Claude でフォルダを開く

  1. Claude アプリの画面上のまん中にある Code（コード） タブを押します。
    「アップグレード」と表示されたら、有料プランへの登録が必要です。
  2. 実行場所は Local（ローカル） を選びます。
  3. Select folder（フォルダを選択） を押して、poko-ai-company を選びます。
🔑 ポイント：中のファイルではなく、フォルダごと選びます。
STEP 4

「はじめまして」と送る

  1. 入力欄に「はじめまして」と入力して送ります。
  2. 秘書のエリーが、ひとつずつ質問します。答えていきましょう（10分くらい）。
  3. わからない質問は「とばす」と送ればOK。あとから変えられます。
  4. 最後に「メニュー」が表示されたら、準備完了です 🎉

※ エリーがファイルを保存するときなどに「許可しますか？」と確認されます。内容を見て、問題なければ許可してください。

5

STEP 5　おすすめ

メール・カレンダーとつなぐ

つなぐと「メールチェック」や、カレンダーへの「アラーム登録」がもっと便利になります。

  1. 文字を入力する欄の横にある ＋ ボタンを押して、Connectors（コネクタ） を選びます。
  2. Gmail と Google カレンダー を選びます。
  3. 画面の案内どおり、Googleアカウントで許可します。
  4. エリーに「メールをチェックして」と話しかけて、動くか試してみましょう。
💡 つながなくても大丈夫。アラームは「カレンダーに追加できるファイル」で届くので、ダブルクリックするだけでカレンダーに入ります。
🔒 安心ポイント：ゆうぴんは、メールを読む・仕分ける・下書きをつくるまで。送信や削除は、あなたが「OK」と言うまでしません。

使い方

ふだんの言葉でOK。「メニュー」と送ると、できることが全部見られます。

「田中さんに領収書」領収書の発行と記録

「メールチェックして」メールの仕分け

「予約アプリつくって」アプリづくり

「明日9時にリマインド」アラーム

office フォルダの index.html をダブルクリックすると、AI社員の働くようすが見られます。「オフィスの色を変えて」と頼めば、模様替えもできます。

困ったら

引っかかったときの聞き方

わからないことは、Claude にそのまま聞くのがいちばん早いです。専門用語がわからなくても大丈夫。

① スクショで聞く（おすすめ）

  1. 困っている画面のスクリーンショットを撮ります。
    Mac
    Shift＋Command＋4 で範囲を選ぶ
    Windows
    Windows＋Shift＋S で範囲を選ぶ
  2. 入力欄に貼りつけます（Mac Command＋V ／ Windows Ctrl＋V）。画像をドラッグしてもOK。
  3. 「この画面になりました。どうしたらいいですか？」と送ります。

② 文章で聞く

この3つを書くと、答えが早く正確になります。

やろうとしたこと：オフィス画面を開こうとした

起きたこと：真っ白な画面になった

どうしたいか：画面を表示したい

③ どこで聞く？

  • ふだんの困りごと → いつもの Code タブで、エリーに聞く
  • Code タブが開けない・動かない → Claude アプリの Chat タブで聞く
  • それでも解決しない → 購入者サポート aoki.miho.824@gmail.com

Q&A

よくある質問

「許可しますか？」と聞かれた
エリーがファイルを保存したり、ツールを使ったりするときの確認です。内容を見て、問題なければ許可してください。
「Git is required」と表示された（主に Windows）
Claude アプリを最新版に更新してください（Windows：Help → Check for Updates ／ Mac：Claude → Check for Updates）。それでも出る場合は、公式サイト（git-scm.com）から「Git for Windows」を入れて、もう一度開いてください。
ターミナルや GitHub の登録は必要？
必要ありません。ぽこAIカンパニーは、パソコンの中のフォルダだけで動きます。
エリーが設定を忘れたみたい
「わたしのこと を読み直して」と伝えてください。
オフィス画面の文字の形がいつもと違う
インターネットにつながっていないと、かわいい丸文字フォントが読み込めず、パソコンに入っている文字で表示されます。動きは同じなので安心してください。
間違えて大事なファイルを消してしまった
購入時のZIPを、もう一度展開すれば元に戻せます。わたしのこと と できたもの のフォルダは、ときどきバックアップしておくと安心です。
