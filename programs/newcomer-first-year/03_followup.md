# 03. フォローアップ研修（6か月後・12か月後）

> なぜフォローアップが必要か
> - 研修直後の効果は時間とともに薄れやすい。ACTの職場研究でもフォローアップ時の効果はやや小さくなる（Unruh et al. 2022）
> - 入社直後の手厚い支援は時間とともに減っていき、その「減り方」が新人の適応を左右する（Kammeyer-Mueller et al. 2013）
> - キャリア初期の適応のターニングポイントは **入社2年目**（尾形）。「慣れた頃」と「後輩が入る頃」に、別の種類の揺れが来る
>
> そのため、6か月後は **「慣れの後の揺れ」への対応**、12か月後は **「2年目への橋渡し」** をテーマにする。

---

# Part 1：6か月後フォローアップ研修（3時間）

## 「慣れた頃に来る揺れ」と、自分を守るやさしさ

### この時期の新人に起きやすいこと
| 起きやすいこと | 心の中 |
|---|---|
| 「できて当然」扱いが始まる。支援が減る | 「もう新人じゃないのに、まだできない」 |
| 同期との差が見え始める（配属・成績・評価） | 「あいつはもう〇〇を任されてるのに」（比較の罠） |
| 最初のショックは越えたが、疲れが溜まっている | 「なんとなくやる気が出ない」「朝がしんどい」 |
| 理不尽な要求・断れない仕事が増える | 「断ったら評価が下がる」（評価過敏の再燃） |

### ゴール
1. 6か月間の自分の回復の **実績** を確認し、自己効力感を高める
2. 「やさしいセルフコンパッション」に加え、**「守るセルフコンパッション」（境界線・断る）** を身につける
3. 比較の罠から抜け、**「過去の自分」との比較** に切り替える
4. NVCで **「断る」「意見を言う」** 台本を持つ

### タイムテーブル

| 時間 | 内容 | 形式 |
|---|---|---|
| 0:00–0:20 | チェックイン：「この半年の心の天気」 | 個人→班 |
| 0:20–0:50 | ワーク①「私の回復の実績」：マイ・リカバリープランの見直し | 個人→ペア |
| 0:50–1:20 | 講義①＋ワーク②「比較の罠」と過去の自分との比較 | 講義→個人 |
| 1:20–1:30 | 休憩 | |
| 1:30–2:10 | 講義②＋ワーク③「守るセルフコンパッション」と境界線 | 講義→個人 |
| 2:10–2:45 | ワーク④ NVCで「断る・意見を言う」ロールプレイ | 3人組 |
| 2:45–3:00 | マイ・リカバリープラン ver.2 の作成 | 個人 |

### 詳細

#### 0:00–0:20 チェックイン「この半年の心の天気」
- 第1回のワーク①（心の天気）を延長して、入社〜6か月の天気を書く
- 「⛈️から☁️や🌤️に戻れた時、何がきっかけだった？」を書く（**回復した場面に注目する**のがポイント）

#### 0:20–0:50 ワーク①「私の回復の実績」
- PAUSEログ・マイ・リカバリープランを見ながら：
  1. PAUSEのうち、一番使えたステップ、一番使えなかったステップは？
  2. 「前の自分なら固まっていたけど、今回は戻れた」場面を1つ書く
  3. 「戻れなかった」場面を1つ書く → 何が足りなかった？（スキル？ 環境？ 疲れ？）
- ペアで「戻れた話」だけを共有 → 聞き手は「その時、何を大切にしていたと思う？」と価値を返す
- 講師解説：自己効力感の最大の源は **「自分でできた」という体験**。回復を「ちゃんと記録して思い出す」ことで、次に折れた時の土台になる

#### 0:50–1:20 講義①＋ワーク②「比較の罠」
- **講義**：
  - 同期との比較は、自分に不利な面ばかりを選んで比べやすい（他人の「表」と自分の「裏」を比べている）
  - 比較そのものを止めることはできない（脳は自動的に比べる）→ 比較してしまったら **S（脱フュージョン）**：「『あいつより劣っている』という考えが浮かんでいる」
  - 比べる対象を「過去の自分」に切り替える（既存教材「誰かになろうとする努力は失敗に終わる」と接続）
- **ワーク②「4月の自分への手紙」**
  - 入社直後の自分に、今の自分から手紙を書く
  - 「あの時できなかったけど、今できること」「あの時心配していたけど、大丈夫だったこと」「あの時の自分に、かけてあげたい言葉」
  - （共有は任意）

#### 1:30–2:10 講義②＋ワーク③「守るセルフコンパッション」
- **講義**：
  - セルフコンパッションには2つの顔がある
    | やさしいセルフコンパッション（受容） | 守るセルフコンパッション（行動） |
    |---|---|
    | 「つらいね」と自分をいたわる | 「これ以上は無理」と自分を守る |
    | 傷ついた後のケア | 傷つく前の境界線 |
    | 第1回で学んだ U | 今回学ぶ |
  - 半年経つと「断れない」「全部引き受ける」による消耗が増える。評価過敏な人ほど「断る＝評価が下がる」と考えやすい
  - **課題の分離**：自分がコントロールできること／できないことを分ける（既存教材「課題の分離・境界線」と接続）
- **ワーク③「コントロールの円」**
  - 今抱えている悩みを1つ選び、2つの円に仕分ける
    - 内側（自分でコントロールできる）：自分の行動、準備、誰に相談するか、断り方
    - 外側（コントロールできない）：上司の機嫌、お客さんの反応、評価の結果、同期の成績
  - 内側にあることから「最小の一歩」を1つ選ぶ（E）
  - 外側にあることには「今、手放す」と心の中で言う（ACTのアクセプタンス）

#### 2:10–2:45 ワーク④ NVCで「断る・意見を言う」
- **NVCの「NO」は、相手のニーズへの「YES」と一緒に伝える**
- **台本④：断る／調整する**
  > 「（観察）今、〇〇と△△の2件を今週中に進めています。（感情）新しい件もお役に立ちたいのですが、このままだと全部が中途半端になりそうで不安です。（ニーズ）どれも質を落とさず仕上げたいので、（リクエスト）優先順位を一緒に決めていただけますか？」
- **台本⑤：違う意見を言う**
  > 「（観察）〇〇の進め方について、（ニーズ）お客さんに一番伝わる形にしたいと思っていて、（リクエスト）一点だけ、別の案をお話ししてもいいですか？」
- 3人組でロールプレイ（新人役／上司役／観察役）。上司役には「最初は渋る」役をしてもらい、2往復目でどう返すかを練習

#### 2:45–3:00 マイ・リカバリープラン ver.2
- 第2回で作ったプランを更新：
  - 新しく分かった「サメモードになりやすい場面」
  - 新しく使える台本（断る・意見を言う）
  - 頼れる人リストの更新（半年で増えた人）
  - 守るセルフコンパッションのフレーズ：「私の時間とエネルギーも大切にしていい」

# Part 2：12か月後フォローアップ研修（3時間）

## 「1年目の物語を書き直す」—— 2年目へ、そして後輩を迎える側へ

### この時期に起きやすいこと
| 起きやすいこと | 心の中 |
|---|---|
| 後輩が入ってくる | 「先輩らしくしなきゃ」「後輩より劣ってたらどうしよう」 |
| 「新人だから」が通用しなくなる | 「もう言い訳できない」というプレッシャー |
| 2年目の憂鬱（尾形）：慣れによる単調さ・成長実感の低下 | 「この仕事、このままでいいのかな」 |
| 1年間の疲れ・燃え尽き | 「頑張ってきたけど、なんのため？」 |

### ゴール
1. 1年間を「失敗の物語」ではなく **「回復と成長の物語」** として書き直す
2. 2年目に向けて、**働く上での価値** を再確認・更新する
3. 自分が身につけた PAUSE とNVCを、**後輩・同僚との関わりに使える**（イルカモードを人にも）
4. 2年目のセルフケア計画を立てる

### タイムテーブル

| 時間 | 内容 | 形式 |
|---|---|---|
| 0:00–0:20 | チェックイン：1年間の心の天気・総集編 | 個人 |
| 0:20–1:00 | ワーク①「1年目の物語を書き直す」 | 個人→ペア |
| 1:00–1:30 | ワーク②「価値の再確認：2年目の私が大切にしたいこと」 | 個人→班 |
| 1:30–1:40 | 休憩 | |
| 1:40–2:20 | 講義＋ワーク③「後輩を迎える側の心理学：イルカモードを人にも」 | 講義→ロールプレイ |
| 2:20–2:45 | ワーク④「2年目のセルフケア計画」 | 個人 |
| 2:45–3:00 | クロージング：同期への「感謝と応援のメッセージ」 | 全体 |

### 詳細

#### 0:00–0:20 チェックイン
- 入社〜12か月の心の天気を1枚に（6か月研修の分と合わせる）
- 4月・10月・今の「PAUSEの使いやすさ」を10段階で

#### 0:20–1:00 ワーク①「1年目の物語を書き直す」
- 人は経験を「物語」として記憶する。同じ1年でも、どの場面に焦点を当てるかで物語は変わる
- 3幕で書く：
  1. **第1幕「つまずき」**：一番つらかった場面（脱フュージョンを使って「事実」として書く）
  2. **第2幕「立て直し」**：その時／その後、自分は何をした？ 誰が助けてくれた？ 何を大切にしていた？
  3. **第3幕「今の自分」**：その経験があったから、今できること・分かること
- タイトルをつける（例：「怒られて、聞けるようになった1年」）
- ペアで共有（任意）。聞き手は「第2幕で、あなたの〇〇（価値・強み）が見えた」と返す
- 講師解説：つらい出来事の後に成長を見いだすことは珍しくない。ただし「つらかったこと」をなかったことにする必要はない（U：つらかったことも認める）

#### 1:00–1:30 ワーク②「価値の再確認」
- 第2回で選んだ価値カードを再び並べる
- 「1年前に選んだ価値は今も一番か？」「新しく大切になったものは？」
- 2年目の自分がその価値に沿って取る行動を、「仕事」「人との関わり」「自分のケア」の3領域で1つずつ書く（既存教材「領域ごとに価値を明確化する」と接続）

#### 1:40–2:20 講義＋ワーク③「後輩を迎える側の心理学」
- **講義**：
  - 新人に「助けを求められる場」をつくるのは、制度より **身近な先輩の反応** である（心理的安全性：Edmondson 1999）
  - 自分が1年前に一番言ってほしかった言葉は何だったか？
  - 先輩の「失敗の見方」は後輩に伝わる（Haimovitz & Dweck 2016の外挿）。「失敗＝学びのデータ」と言える先輩になる
  - 後輩がサメモードになっている時、まず **理解** から（既存イルカマスターコース「何かするんじゃなくて、まずは理解から」）
- **後輩向けの関わり方**（PAUSEの対人版）
  | 後輩の状態 | 先輩の関わり |
  |---|---|
  | 固まっている | 「今どんな感じ？」（A を手伝う） |
  | 自分を責めている | 「自分も1年目に同じことやったよ」（U：共通の人間性） |
  | 「自分はダメだ」と言う | 「そう思っちゃうよね。で、実際に起きたことは何だった？」（S：事実と解釈を分ける） |
  | 動けない | 「次の一歩、一番小さくすると何？」（E） |
- **ロールプレイ**：後輩役がケースカードの状況を話し、先輩役が上の関わりを試す
- 補足：後輩の面倒を見ることで、自分のスキルが定着する（教えることは最大の学習）。ただし **抱え込みすぎない**（守るセルフコンパッション）

#### 2:20–2:45 ワーク④「2年目のセルフケア計画」
- 心身の土台チェック（既存教材の5要素）：睡眠・朝の光・食事・運動・自然
- 2年目に予想される「揺れ」とその対策
- 「研修では足りないサイン」と相談先の再確認
- **マイ・リカバリープラン ver.3**（最終版）として、手帳やスマホに保存

#### 2:45–3:00 クロージング
- 同期への「感謝と応援のメッセージ」カード（匿名可）を交換
- 講師から：「1年間、何度もサメモードになりながら、ここまで戻ってきたこと自体が、あなたの回復力の証拠です」

## フォローアップ研修の効果測定

| 時点 | 測定 |
|---|---|
| 6か月研修前（T2） | SCS-SF、AAQ-II/WAAQ、Brief FNE、BRS、K6、UWES-9、PAUSE使用頻度、援助要請頻度 |
| 12か月研修前（T3） | 上記 ＋ 人事データ（1年後在籍率、休職、上司評価、営業の場合は成約数など） |
| 12か月研修後 | 研修全体の振り返りアンケート（「1年間で一番役に立ったスキル」「後輩に伝えたいこと」） |

**報告書の構成例（企業向け）**：
1. 参加者の心理指標の推移（T0→T1→T2→T3、集団平均）
2. 在籍率・休職数の前年度比較
3. 参加者の声（匿名）
4. 研修で見えた職場環境の課題（匿名化）と提案
