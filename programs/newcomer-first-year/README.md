# 入社1年目に学ぶ 職場の心理学
## 〜 心が折れても、自分で立て直せる人になる 〜
### 新人向けフォロープログラム（メンタルジム 法人版）

---

### 背景：現場の声

- 「心が折れる新人への対応が大変」と感じるマネジャー・先輩が多い
- 営業でも、お客さんに怒られて心が折れ、営業に行けなくなる。「営業だから」が通じなくなってきている
- 評価への過敏さ、心の折れやすさ、シャットダウン（固まる・避ける）のしやすさ

### このプログラムの考え方

> **「折れない心」をつくるのではなく、「折れても自分で立て直せる心」を育てる。**

新人が、叱られた・お客さんに怒られた・ミスした直後に、**ひとりで使える立て直し手順「PAUSE（ポーズ）」** を身につけます。
セルフコンパッション・ACT（アクセプタンス＆コミットメント・セラピー）・NVC（非暴力コミュニケーション）を組み合わせ、
既存メンタルジムの「サメモード（防衛）→ イルカモード（安心）」の枠組みに沿って設計しています。

| | ステップ | 背景理論 |
|---|---|---|
| **P** | 止まる（Pause） | マインドフルネス |
| **A** | 名前をつける（Acknowledge） | 感情ラベリング |
| **U** | いたわる（Understand with kindness） | セルフコンパッション |
| **S** | 思考と離れる（Separate） | ACT 脱フュージョン |
| **E** | 価値に沿って動く・伝える（Engage） | ACT 価値／NVC |

### 主要な根拠（詳細は `01_evidence.md`）

- 新人の適応は「役割の明確さ・自己効力感・社会的受容」で決まる（Bauer et al., 2007, *JAP* メタ分析）
- セルフコンパッションが高い人は、否定的評価を受けても落ち込みが小さく、責任は認める（Leary et al., 2007, *JPSP*）
- 失敗後のセルフコンパッションは改善意欲を高める（Breines & Chen, 2012, *PSPB*）
- セルフコンパッション介入のRCTメタ分析：ストレス g=0.67、抑うつ g=0.66（Ferrari et al., 2019, *Mindfulness*）
- 職場ACTのRCTメタ分析：心理的苦痛 g=−0.38、特にオフィスワーカーで有効（Unruh et al., 2022, *JCBS*）
- 心理的柔軟性は1年後のメンタルヘルスと業績を予測（Bond & Bunce, 2003, *JAP*）
- 顧客からの不当な扱いは情緒的消耗・離職意図と関連（Arvan et al., 2019 メタ分析）。感情を押し殺す表層演技は消耗を強める（Hülsheger & Schewe, 2011 メタ分析）
- 大卒の3年以内離職率 33.8%（厚生労働省, 2025年公表）
