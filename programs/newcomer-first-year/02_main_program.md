# 02. 本研修プログラム案

# 入社1年目に学ぶ 職場の心理学
## 〜 心が折れても、自分で立て直せる人になる 〜

---

## 0. プログラム概要

| 項目 | 内容 |
|---|---|
| 対象 | 新入社員（入社1〜3か月目）。1クラス12〜24名（4名×班） |
| 形式 | **全2回 × 各3時間**（対面またはオンライン）＋ 間の2週間の実践課題 |
| 推奨時期 | 第1回：配属直後〜1か月以内（最初の「ショック」が起きる時期） ／ 第2回：その2週間後 |
| 同時実施 | 上司・OJT担当向け 90分セッション（→ `04_toolkit.md` 第3章） |
| フォロー | 6か月後・12か月後フォローアップ研修（→ `03_followup.md`） |
| 監修・講師 | 臨床心理士・公認心理師 |
| 中核スキル | **PAUSE（ポーズ）**：心が折れそうな時に、自分で立て直す5ステップ |

### このプログラムで新人が持ち帰るもの

1. **「心が折れる仕組み」の理解** — 自分が弱いのではなく、脳の防衛反応（サメモード）だと分かる
2. **PAUSE 5ステップ** — 叱られた／お客さんに怒られた／ミスした直後に、ひとりで使える立て直し手順
3. **3つの台本** — 「助けを求める」「フィードバックを取りにいく」「怒っている相手に向き合う」ための言葉（NVC）
4. **自分の「働く上での価値」** — 不安があっても動き出すための羅針盤（ACT）

### やらないこと（設計上の約束）

- ❌ 「ポジティブに考えよう」「気にしないようにしよう」（感情の抑圧は消耗を強める：Hülsheger & Schewe 2011）
- ❌ 「営業なんだから慣れろ」「みんな通ってきた道」（孤立感を強め、援助要請を減らす）
- ❌ 自分の弱さの告白を強制するワーク（評価過敏な層には逆効果。**共有はすべて任意**）
- ❌ 研修で治療をすること（強い不調のサインがある人は専門職につなぐ）

## 1. 中核モデル：「サメモード」と「PAUSE」

### 1-1. サメモード／イルカモード（既存メンタルジム教材の枠組みを継承）

| | サメモード（防衛） | イルカモード（安心） |
|---|---|---|
| 状態 | 危険を察知して身を守ろうとしている | 安心をベースに、理解・好奇心で動いている |
| 職場での姿 | 指摘を攻撃と感じる／言い訳する（戦う）・電話を避ける、上司を避ける（逃げる）・頭が真っ白になる、手が止まる（固まる） | 指摘を「情報」として受け取る・分からないことを聞ける・相手の事情を想像できる |
| 頭の中の声 | 「怒られた＝嫌われた」「自分は向いてない」「もう終わりだ」 | 「今、悔しいんだな」「ここを直せば良い」「誰に聞けばいいかな」 |

**ポイント**：サメモードは悪者ではない。脳があなたを守ろうとしているサイン。
問題は「サメモードになること」ではなく **「サメモードから戻れないこと」**。
新人の時期は、評価される場面・初めての場面が続くため、誰でもサメモードになりやすい。

### 1-2. PAUSE（ポーズ）：サメモードからイルカモードに戻る5ステップ

| | ステップ | やること | 一言フレーズ | 心理学的背景 |
|---|---|---|---|---|
| **P** | **Pause** 止まる（一時停止） | 反応する前に、ひと呼吸。足の裏を感じる／息を長く吐く（6秒） | 「いったん、止まる」 | マインドフルネス、ACT「今この瞬間」 |
| **A** | **Acknowledge** 認める | 今の感情に名前をつける（怒り？の下にある悔しさ・恥ずかしさ・怖さ） | 「今、私は〇〇を感じている」 | 感情ラベリング（Lieberman 2007） |
| **U** | **Unhook** 外す | 考えの釣り針から外れる。頭の声を「〜という考えが浮かんでいる」と言い直す。事実と解釈を分ける | 「『自分はダメだ』という考えが浮かんでいる」 | 認知的脱フュージョン（Masuda 2004）。「Unhook」はACT実践家R. HarrisやS. Davidが使う平易な表現 |
| **S** | **Self-compassion** 自分を思いやる | 親友にかける言葉を自分にかける。「こんな時、誰でもつらい」 | 「つらいよね。新人なら誰でもそうなる」 | セルフコンパッション3要素（Neff 2003） |
| **E** | **Engage** 取り組む | 不安があってもいい。大切にしたいことに沿った「最小の一歩」を選ぶ。必要なら助けを求める（NVC） | 「不安なまま、次の一歩」 | ACT価値とコミットされた行為、NVC |

> 💡 **日本語で覚える**：**止まる・認める・外す・思いやる・取り組む**
> 💡 **研修で扱う順番**：第1回で P・A・S（気持ちを受け止める側）、第2回で U・E（考えと行動の側）を学ぶ。実際に使う時は PAUSE の順。
> 💡 **時間の目安**：P〜Sは慣れれば **30秒〜3分**。トイレや移動中、商談後の車の中でできる。
> Eは「次の電話を1本かける」「先輩に5分相談する」など、5分以内にできる行動に限定する。

## 2. 第1回（3時間）：「心が折れる仕組み」を知り、自分を思いやる

### 第1回のゴール
- 心が折れる・シャットダウンするのは「弱さ」ではなく「防衛反応」だと理解する
- PAUSE の **P・A・S**（止まる・認める・自分を思いやる）を体験する
- 「自分に優しくする＝甘え」という思い込みを、データで外す

### タイムテーブル

| 時間 | 内容 | 形式 |
|---|---|---|
| 0:00–0:15 | オープニング・安心の場づくり | 講義 |
| 0:15–0:45 | ワーク①「入社してからの心の天気」 | 個人→ペア |
| 0:45–1:15 | 講義①「心が折れる」の正体：サメモードと3つの反応 | 講義 |
| 1:15–1:25 | 休憩 | |
| 1:25–1:55 | ワーク②「感情に名前をつける」（P・A） | 個人→班 |
| 1:55–2:25 | 講義②＋ワーク③「親友ならなんて言う？」（S） | 講義→個人 |
| 2:25–2:50 | ワーク④「PAUSE 前半を通してやってみる」 | ペア |
| 2:50–3:00 | まとめ・実践課題の説明 | 講義 |

### 詳細

#### 0:00–0:15 オープニング・安心の場づくり
- グラウンドルール（スライドに常時表示）
  1. 話したくないことは話さなくていい（パスOK）
  2. ここで聞いた話は外に出さない
  3. 正解はない。「そう感じた」がすべて正解
  4. この研修の内容は **人事評価に一切使わない**（事前に人事と合意しておく）
- 講師の自己開示：講師自身の新人時代の「心が折れた」エピソードを1つ（評価過敏な層にとって、権威者の失敗談は「ここでは弱さを出してもいい」という強いシグナルになる）

#### 0:15–0:45 ワーク①「入社してからの心の天気」
- 入社〜今日までの時間軸に、心の天気（☀️🌤️☁️🌧️⛈️）を書き込む
- 「⛈️の時、何があった？」「その時、どうした？（戦う／逃げる／固まる）」を書く
- ペアで **話せる範囲だけ** 共有
- 講師の問いかけ：「⛈️がなかった人、いますか？」→ ほぼ全員に⛈️があることを可視化する（**共通の人間性**：「自分だけじゃない」）
- データ提示：「入社後、4人に3人がリアリティ・ショックを経験している（76.6%）」

#### 0:45–1:15 講義①「心が折れる」の正体
1. **脳は「評価される場面」を危険として扱う**
   - 人間にとって集団から外されることは生存の危機だった → 否定的評価への恐れは自然な反応
   - 新人は「初めて」「評価される」が毎日続く → サメモードになりやすい時期
2. **3つの反応**（戦う／逃げる／固まる）と、職場での具体例
   - 営業の例：お客さんに怒鳴られた → 次の訪問先に行けない（逃げる）、車の中で30分動けない（固まる）、「あの客がおかしい」と同期に愚痴り続ける（戦う）
3. **シャットダウンの悪循環**（ACTの体験の回避モデル）
   ```
   つらい出来事 → 不快な感情 → 避ける（電話しない・聞かない）
        ↑                                    ↓
   自信がさらに下がる ← 仕事が滞る ← 一時的にホッとする
   ```
   - 「避けるとホッとする」から回避は癖になる。意志が弱いからではなく、**脳の学習の仕組み**。
4. **評価過敏な人ほど、実は優秀なことが多い**
   - リスクを先読みし、ちゃんとやろうとする人ほど、評価に敏感になる（既存メンタルジム教材の「不安はお守り」の考え方）
   - 問題は感受性そのものではなく、それに **振り回される** こと
5. **研究データ**：
   - 指摘の約3分の1は、受け手の注意が「自分という人間」に向くと逆にパフォーマンスを下げる（Kluger & DeNisi 1996）
   - 対人過敏な新人ほど、困っても助けを求められない（援助要請研究）

#### 1:25–1:55 ワーク②「感情に名前をつける」（P・A）
- **P（止まる）の練習**：60秒、足の裏の感覚に注意を向ける／4秒吸って6秒吐く呼吸を3回
- **A（名前をつける）の練習**：
  - 最近の「⛈️」場面を1つ思い出す（強すぎない、10段階で4〜5程度のもの）
  - 「感情ことばリスト」（`04_toolkit.md` 付録）から当てはまる言葉を選ぶ
  - 表に出ている感情（イライラ）の下にある **一次感情**（悔しい・恥ずかしい・怖い・寂しい・不安）を探す
- 班で共有：「名前をつける前と後で、10段階の強さは変わった？」
- 講師解説：感情に名前をつけるだけで、脳の警報装置（扁桃体）の反応が下がる（Lieberman 2007）。「Name it to tame it（名づければ、手なずけられる）」

#### 1:55–2:25 講義②＋ワーク③「親友ならなんて言う？」（S）
- **講義**：
  - 「自分に厳しくしないと成長しない」は本当か？
    - 失敗後に自分に思いやりを向けた人の方が、**改善への意欲が高く、長く勉強した**（Breines & Chen 2012）
    - セルフコンパッションが高い人は、否定的な評価を受けても落ち込みが小さく、**しかも自分の責任は認める**（Leary et al. 2007）
  - セルフコンパッションは「甘やかし」ではない
    | 甘やかし | セルフコンパッション |
    |---|---|
    | 「もういいや」と現実から目を背ける | 「つらいね」と現実を見た上で、自分を支える |
    | 結果：停滞 | 結果：回復と次の一歩 |
  - 3つの要素：①自分へのやさしさ ②共通の人間性（自分だけじゃない） ③マインドフルネス（大げさにも無視もしない）
- **ワーク③ フレンドトレーニング**（既存「セルフコンパッション・プレイブック」WORK 01を新人向けに改変）
  1. 同期の親友が、あなたと全く同じ失敗をして落ち込んでいる場面を想像する
  2. その親友にかける言葉を書く
  3. 同じ場面で、自分が自分にかけている言葉を書く
  4. 2と3のギャップを見る → 2の言葉を、主語を自分にして読み上げる（心の中で）
  5. 手を胸に当てる／腕をさする（スージングタッチ）を試す（任意）

#### 2:25–2:50 ワーク④「PAUSE 前半を通してやってみる」
- ペアで、ケースカードを1枚引く（`04_toolkit.md` ケースカード集）
  - 例：「先輩から、みんなの前で『これ、前も言ったよね？』と言われた」
  - 例：「お客さんに『新人をよこすなんて、うちを舐めてるのか』と言われた」
- P → A → S を声に出して（または紙に書いて）実施。相手はただ聞く（アドバイス禁止）
- 交代

#### 2:50–3:00 まとめ・実践課題
- **2週間の実践課題：PAUSEログ**（`04_toolkit.md` 第1章）
  - 1日1回、心が少しでも揺れた場面で P・A・S をやり、30秒で記録する
  - 揺れなかった日は「今日の小さなできた」を1つ書く
  - 書けなかった日があってもOK（できなかった自分にもS）

## 3. 第2回（3時間）：思考と距離をとり、動き出す・伝える

### 第2回のゴール
- PAUSE の **U・E**（考えから外れる・価値に沿って取り組む）を身につける
- 自分の「働く上での価値」を言葉にする
- NVC で「助けを求める」「フィードバックを取りにいく」「怒っている相手に向き合う」台本を持つ

### タイムテーブル

| 時間 | 内容 | 形式 |
|---|---|---|
| 0:00–0:20 | PAUSEログの振り返り | 班 |
| 0:20–1:00 | 講義③＋ワーク⑤「頭の声の釣り針を外す」（U） | 講義→個人→ペア |
| 1:00–1:30 | ワーク⑥「私が働く上で大切にしたいこと」（E：価値） | 個人→班 |
| 1:30–1:40 | 休憩 | |
| 1:40–2:20 | 講義④＋ワーク⑦「NVCで伝える：3つの台本」（E：行動） | 講義→ロールプレイ |
| 2:20–2:45 | ワーク⑧「PAUSE フルバージョン」ロールプレイ | 3人組 |
| 2:45–3:00 | まとめ・「マイ・リカバリープラン」作成 | 個人 |

### 詳細

#### 0:00–0:20 PAUSEログの振り返り
- 班で共有：「やってみて、何が起きた？」「できなかった時、何が邪魔した？」
- 講師は「できなかった」報告を最も歓迎する（「それが大事なデータです」）

#### 0:20–1:00 講義③＋ワーク⑤「頭の声の釣り針を外す」（U：脱フュージョン）
- **講義**：
  - 頭の中の声は「事実」ではなく「脳が出した仮説」
  - フュージョン（思考と一体化）：「私はダメだ」＝事実だと感じている状態
  - 脱フュージョン：「『私はダメだ』という考えが浮かんでいる」と気づいている状態
  - 否定的な自己関連思考は、短い脱フュージョン練習で **信じ込み度・不快感が下がる**（Masuda et al. 2004）
  - 不安や考えを **消す** のではなく、**持ったまま動ける** ようにするのがゴール（「51％の安心」の考え方）
- **ワーク⑤**（以下から2〜3つを体験）
  1. **「〜という考えが浮かんでいる」言い換え**
     - 「私は営業に向いてない」→「『私は営業に向いてない』という考えが浮かんでいる」→「『私は営業に向いてない』という考えが浮かんでいることに、気づいている」
  2. **事実と解釈の仕分け表**
     | 起きたこと（カメラに映る事実） | 私の頭が言ったこと（解釈） |
     |---|---|
     | 課長が資料を見て「ここ違う」と言った | 「課長は私を無能だと思っている」 |
     | お客さんが「もういい」と電話を切った | 「私のせいで会社に迷惑をかけた。もう終わりだ」 |
  3. **頭の声に名前をつける**：よく出てくる否定的ストーリーに名前をつける（例：「どうせ嫌われる劇場」「向いてない物語」）。出てきたら「あ、また『向いてない物語』が始まった」
  4. **フィードバックの仕分け**：指摘を「①課題に関する情報」「②相手の感情・言い方」「③私についての解釈」の3つに分ける → ①だけを持ち帰る
- 既存教材の「18個のネガティブストーリー」と接続し、自分のよく出るストーリーを1つ選ぶ

#### 1:00–1:30 ワーク⑥「私が働く上で大切にしたいこと」（E：価値）
- **講義（5分）**：
  - 価値＝「どこへ向かいたいか」という方角。ゴール（達成するもの）とは違う
  - 不安があっても動けるのは、「何のために」が分かっている時
  - 心理的柔軟性（不安を持ちながら価値に沿って動ける力）は、**1年後のメンタルヘルスと業績を予測する**（Bond & Bunce 2003）
- **ワーク**：
  1. 価値カード（`04_toolkit.md`）から、仕事で大切にしたいものを5枚 → 3枚 → 1枚に絞る（例：誠実、成長、貢献、つながり、挑戦、丁寧さ、信頼）
  2. 「その価値を大切にしている自分は、明日、職場でどんな小さな行動をする？」を3つ書く
  3. 営業の例：価値「お客さんの役に立つ」→ 怒られた後の一歩「お客さんが何に困っていたのかをメモする」「先輩に『あのお客さんの背景、知ってますか』と聞く」
- 班で共有：「怒られた・失敗した時でも、この価値は変わる？」 → 価値は評価に左右されない、自分だけのもの

#### 1:40–2:20 講義④＋ワーク⑦「NVCで伝える：3つの台本」
- **講義**：
  - NVCの4要素：**観察 → 感情 → ニーズ → リクエスト**
  - ジャッカル語（評価・非難）とキリン語（感情・ニーズ）—— 他人に対してだけでなく、**自分の頭の中のジャッカル語** にも気づく
  - 相手の怒りも「満たされていないニーズの表現」として聞ける（=深層演技。感情を押し殺す表層演技は消耗を強める：Hülsheger & Schewe 2011）
- **台本①：助けを求める（援助要請）**
  > 「〇〇さん、今5分いいですか？（観察）〇〇の作業で、△△のところが分からなくて手が止まっています。（感情）少し焦っていて、（ニーズ）期限までに正しく仕上げたいので、（リクエスト）進め方だけ教えていただけますか？」
- **台本②：フィードバックを取りにいく**
  > 「先ほどの商談、（観察）〇〇の説明の時にお客さんの反応が薄かったと感じました。（ニーズ）次はもっと伝わるようにしたいので、（リクエスト）1つだけ改善点を教えていただけますか？」
  - 「1つだけ」と範囲を限定するのがコツ（評価過敏な人でも受け取りやすい量にする）
- **台本③：怒っている相手に向き合う**（顧客・上司）
  - 心の中で（自分へのキリン語）：「（A）今、私は怖い。（U）『自分のせいで全部台無し』という考えが浮かんでいる。（S）誰でも怖い。」
  - 相手のニーズを推測：「このお客さんは、何を大切にしたくて怒っているんだろう？（信頼？ 時間？ 尊重？）」
  - 言葉にする：
  > 「〇〇の件で、ご不便をおかけして（相手の観察）お困りになったと思います。（相手の感情）確実に進めたいというお気持ち、（相手のニーズ）よく分かりました。（リクエスト）今日中に上司と確認して、〇時までにご連絡してもよろしいでしょうか？」
  - ⚠️ **境界線**：人格否定・暴言・ハラスメントは「受け止めるもの」ではない。その場を離れる・上司に引き継ぐのも正しい選択（会社としての対応ルールを事前に確認し、研修で明示する）

#### 2:20–2:45 ワーク⑧「PAUSE フルバージョン」ロールプレイ
- 3人組（新人役／相手役／観察役）
- ケース例：
  1. 上司に報告したら「で、結論は？」と遮られた
  2. 架電で3件連続で「結構です」と切られ、4件目がかけられない
  3. 自分のミスでお客さんが怒って、先輩が代わりに謝ってくれた
- 流れ：ケースを演じる → 新人役が P・A・U・S を声に出す（または紙）→ E として台本①〜③のどれかを実演 → 観察役がフィードバック（「良かった点」を先に2つ）

#### 2:45–3:00 まとめ・「マイ・リカバリープラン」作成
- `04_toolkit.md` の「マイ・リカバリープラン」（1枚）を作る
  - 私がサメモードになりやすい場面
  - その時の私のサイン（体・思考・行動）
  - 私の PAUSE フレーズ（自分の言葉で）
  - 私の価値と、最小の一歩
  - 困った時に頼れる人（社内2人・社外1人）
  - 「これは研修では足りない」サイン（眠れない日が2週間続く等）と相談先
- 6か月後のフォローアップ研修の予告：「6か月後、このプランを持ってきてください」

## 6. 営業職向けアレンジ（オプション）

「営業だから」が通じなくなっている現場向けに、第2回の後半を差し替え可能なモジュール。

| 場面 | よくあるサメモード | PAUSE での立て直し例 |
|---|---|---|
| 架電で断られ続ける | 「次も断られる」→ 電話できない（逃げる） | P：受話器を置いて息を吐く → A：「凹んでる、怖い」 → U：「『次も断られる』という予言が浮かんでいる」 → S：「断られて平気な人はいない」 → E：価値「役に立つ情報を届ける」に沿って、次の1件だけかける |
| 商談で厳しく否定された | 車の中で固まる（固まる） | P：シートで足裏を感じる → A：「恥ずかしい、悔しい」 → U：「否定されたのは提案内容。私という人間ではない」 → S：「頑張って準備したもんね」 → E：否定された理由を1行メモ → 先輩に台本②で相談 |
| クレームで怒鳴られた | その場で言い訳・反論（戦う） or 黙り込む（固まる） | 心の中でP・A・U・S → 相手のニーズ推測（台本③）→ 自分の権限外なら「上司に確認して折り返します」で一旦引く（境界線） |
| 数字が未達で詰められた | 「自分は向いてない」で頭がいっぱい | U：数字は「今の結果」、向き不向きは「解釈」 → E：コントロールできる行動量（訪問数・準備）に注意を戻す |

**補足（成果との関係）**：心理的柔軟性は業績を予測する（Bond & Bunce 2003）。既存メンタルジムでも、メンタルが安定した営業職の参加者で成約数が月平均10件→約13件に増えた事例がある（個別事例であり、一般化はできない）。

## 7. 実施上の注意

- **研修は治療ではない**。強い抑うつ・不眠・希死念慮などのサインがある参加者は、研修参加より専門的支援を優先する
- **環境の問題を個人の問題にしない**。ハラスメントや過重労働が原因の場合、新人のスキルで解決すべきものではない。研修で出てきた職場環境の課題は、匿名化した上で人事にフィードバックする仕組みをつくる
- **上司・先輩向けセッションとセットで実施する**。新人が台本①で助けを求めても、「そんなことも分からないの？」と返されたら、回避がかえって強化される
