## 第1章 新人向けワークシート

### 1-1. PAUSE ポケットカード（名刺サイズで印刷・スマホ待ち受け用）

```
┌───────────────────────────────┐
│  心が折れそうな時の PAUSE（ポーズ）     │
│                                       │
│  P  止まる      ひと呼吸。6秒で吐く       │
│  A  名前をつける  「今、私は〇〇を感じてる」 │
│  U  いたわる    「つらいよね。誰でもそうなる」│
│  S  離れる     「〜という考えが浮かんでいる」│
│  E  動く       不安なまま、最小の一歩     │
│                                       │
│  サメモードになるのは、弱いからじゃない。     │
│  戻ってこられれば、それでいい。            │
└───────────────────────────────┘
```

### 1-2. PAUSEログ（1日30秒）

| 日付 | 何があった？（事実だけ） | A：感情の名前 / 強さ(0-10) | U：自分にかけた言葉 | S：浮かんだ考え | E：とった一歩 | 後の強さ(0-10) |
|---|---|---|---|---|---|---|
| 例 5/12 | 課長に資料を「全然違う」と返された | 恥ずかしい・怖い / 7 | 「初めての資料だし、直せばいい」 | 「『期待外れだと思われた』という考え」 | 直す箇所を3つに分けて課長に確認した | 4 |
| | | | | | | |
| | | | | | | |

> できなかった日も、それでOK。「今日はできなかった」と書くこと自体が A（気づき）です。

### 1-5. フィードバック3分割シート

指摘を受けたら、3つに分ける：

| ① 課題についての情報（持ち帰る） | ② 相手の感情・言い方（相手のもの） | ③ 私についての解釈（脱フュージョンする） |
|---|---|---|
| 例：「結論を先に書く」 | 例：課長が急いでいて口調がきつかった | 例：「私は仕事ができない人間だ」 |

## 第2章 ケースカード集（ロールプレイ用）

### 上司・先輩との場面
1. 先輩から、みんなの前で「これ、前も言ったよね？」と言われた
2. 上司に報告したら「で、結論は？」と遮られた
3. 質問したら「それくらい自分で調べて」と言われ、次から聞けなくなった
4. 自分のミスを先輩がフォローしてくれたが、ため息をつかれた
5. 会議で意見を言ったら、誰も反応しなかった

### 顧客との場面（営業・接客）
6. お客さんに「新人をよこすなんて、うちを舐めてるのか」と言われた
7. 架電で3件連続で「結構です」と切られ、4件目がかけられない
8. 自分のミスでお客さんが怒り、先輩が代わりに謝ってくれた
9. 商談で提案を「全然分かってないね」と否定された
10. 月末、数字が未達で上司に詰められた

### 同期・自分との場面
11. 同期が先に大きな仕事を任された
12. 同じミスを2回してしまった
13. 夜、今日の失敗が頭から離れず眠れない
14. 月曜の朝、会社に行きたくない

## 第3章 上司・OJT担当向けガイド（90分セッション用）

### 3-1. このセッションの目的
新人がPAUSEで立て直し、台本で「助けて」「教えてください」と言えるようになっても、受け手の反応次第でその行動は **強化も消去もされる**。
「心が折れる新人への対応が大変」という上司・先輩の負担を減らすために、**新人が自分で立て直せる環境** をつくる。

### 3-2. タイムテーブル（90分）

| 時間 | 内容 |
|---|---|
| 0:00–0:15 | 今の新人に何が起きているか（データ：3年以内離職33.8%、リアリティ・ショック76.6%、正当なFBでも離職を考える） |
| 0:15–0:35 | 「打たれ強さ」から「回復力」へ：新人研修で教えるPAUSEの紹介 |
| 0:35–1:00 | 「折れにくくする」伝え方：フィードバックの3原則（下記）＋ロールプレイ |
| 1:00–1:20 | 新人がPAUSEや台本を使ってきた時の受け止め方 |
| 1:20–1:30 | 上司・先輩自身のセルフケア（支える側も折れる） |

### 3-3. 伝え方の3原則（研究知見に基づく）

| 原則 | NG例 | OK例 | 根拠 |
|---|---|---|---|
| **① 人ではなく課題に向ける** | 「なんでこんなこともできないの？」 | 「この資料、結論を最初に持ってこよう」 | 注意が自己に向くとFBは逆効果（Kluger & DeNisi 1996） |
| **② 失敗を「学びのデータ」として扱う** | 「次ミスしたら許さないよ」 | 「このミスで仕組みの穴が見つかった。何が起きたか一緒に見よう」 | 失敗観は伝わる（Haimovitz & Dweck 2016の外挿）／心理的安全性（Edmondson 1999） |
| **③ 量を絞る** | 10個まとめて指摘 | 「今日は1つだけ。ここを直そう」 | 評価過敏な人が受け取れる量を超えるとシャットダウンしやすい |

### 3-4. 新人が「助けて」と言ってきた時

- まず **「言ってくれてありがとう」**（援助要請という行動そのものを強化する）
- 「そんなことも分からないの？」「前も言ったよね」は、**次の相談をゼロにする** 言葉
- 忙しい時は「今は無理」ではなく「15時なら5分取れる」と代替案を出す

### 3-5. 新人が明らかにサメモード（固まっている・涙ぐんでいる）の時

| やること | 言葉の例 |
|---|---|
| 責めずに状態を確認する | 「今、ちょっとしんどそうに見えるけど、大丈夫？」 |
| 一旦離れる時間を許可する | 「5分休憩してから、もう一回話そう」 |
| 共通の人間性を伝える | 「自分も1年目に同じことでめちゃくちゃ凹んだよ」 |
| 次の一歩を一緒に小さくする | 「まず何から手をつける？ 一番小さいことでいい」 |

### 3-6. 上司・先輩のための注意点
- 新人の回復を「上司が全部背負う」必要はない。**新人自身がPAUSEを持っている** ことを信頼する
- 上司自身もサメモードになる（「最近の若者は」という考えが浮かんだら、それも脱フュージョンの対象）
- 新人に強い不調のサイン（2週間以上続く不眠・食欲低下・遅刻欠勤の増加・「消えたい」などの発言）があれば、**スキルの問題として扱わず**、人事・産業医につなぐ
