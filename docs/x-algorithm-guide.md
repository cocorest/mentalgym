# X（旧Twitter）アルゴリズム 投稿ガイド

小規模アカウント向けにまとめた、評価されるポストとやってはいけないこと。
X投稿の文案づくり・投稿タイミングの相談・投稿チェックの際は、必ずこのガイドに沿って提案する。
💡 = オーナーが特に重視しているポイント（チェック時は優先して確認する）。

## 評価されるポスト

1. **投稿のタイミング**：新しい投稿が優遇されるのは投稿から2時間以内・表示200回まで。深夜に出すと誰も見ないまま終わるので、フォロワーがXを見ている時間に投稿する。48時間経つとおすすめに出なくなる。
2. **評価が高い反応**：リンクのコピー共有 20点／相互フォロー同士のリプ 20点／リプ・引用・DMでの共有 5点／フォローされる 4点／いいね 0.66点（過去最大）。
   → リンクのコピー共有（20）は、いいね（0.66）の約30倍重視されている。
3. **じっくり読まれる**：読まれた時間の評価が以前の1.5倍に。開いて10秒以上読まれると0.4点。
4. **フォロワー外に広がる条件**：届くのは自分のオリジナル投稿だけ。最初に見た人のいいね率が高いほど伸びる。1つ目と32個目のいいねで、フォロワー外への表示が増える。フォロワー5万人以下なら、新しい投稿1件がおすすめの約16番目まで上がることも。
5. **投稿は1つに絞る** 💡：フォロワーのタイムラインに自分の複数の投稿が入ると、2つ目は評価が62%に下がる。数時間あけても重なることがあるため、本数より1件の質を優先。
6. **その他**：動画は10秒以上見られないと動画のおすすめに載らない。📍ピン留めの投稿にリンクがある場合、そのリンク先をXが低評価と判定すると、アカウントに7日間マークされる（判定基準は不明）。

## やってはいけないこと

1. **「興味なし」を押されるような投稿をしない** 💡：大幅減点（-52.27）。開いてすぐ閉じられる内容も加点はわずか（0.3）。
2. **動画だけに頼らない**：動画は開かれても0.02点、見られても0点。動画のおすすめに載るには10秒以上の視聴が必要。
3. **ブックマーク狙いをしない** 💡：保存されても0点。
4. **ハッシュタグを並べない**：いくつ付けても評価は上がらない。
5. **リプやRPで広めようとしない**：フォロワー以外には表示されない。
6. **古い投稿に期待しない**：投稿から48時間でおすすめに出なくなる。
7. **深夜に投稿しない** 💡：誰も見ないまま、投稿直後2時間の優遇が終わる。
8. **連投しない** 💡：自分の投稿同士で評価を食い合う。
9. **誤情報や質の低い投稿をしない** 💡：そう判定されると、フォロワー以外はいいねや共有ができなくなる。
10. **暴言を書かない** 💡：フォロワー以外に表示されなくなる。
11. **成人向け画像・動画を続けて載せない**：直近5投稿中3件でアカウントに警告。警告1つでフォロワー以外に一切表示されなくなる。
12. **スパム扱いされることをしない**：同じ文章の使い回し、無関係な人のタグ付け＋質の低いリンク、いいね・RPのおねだり（フォロワー数に関係なく対象）。
13. **人気アカウントのリプ欄で、自分のリプに自分でリプを重ねない**：評価がゼロになる恐れ。
14. **動画に宣伝を紛れ込ませない**：64いいねで審査、512いいねでさらに厳しく。
15. **ピン留め投稿📍に評価の低いリンクを貼らない**：アカウントに7日間マークされることがある（判定基準は不明）。

## まとめ

「質の高い1投稿を、適切なタイミングで、適切に届けること」が大事。

## 投稿作成時のチェックリスト（Claude用）

- [ ] 1回で完結する1投稿にまとまっているか（スレッド連投・同日の複数投稿を避ける）
- [ ] 冒頭で「興味なし」「即閉じ」されない引きがあり、10秒以上読まれる中身があるか
- [ ] 誤情報・強い言葉・暴言になっていないか（メンタル系の発信なので特に表現に配慮）
- [ ] ハッシュタグを並べていない／いいね・RPのおねだりをしていない
- [ ] 過去投稿の使い回しになっていない
- [ ] 「誰かに送りたい・リンクをコピーしたい」と思える内容か、相互フォローからリプが来る問いかけがあるか
- [ ] 投稿時間はフォロワーがXを見ている時間帯か（深夜を避ける）
- [ ] 動画を使う場合、10秒以上見られる構成か・宣伝を紛れ込ませていないか
- [ ] ピン留めにリンクを貼る場合、リンク先の質は大丈夫か
