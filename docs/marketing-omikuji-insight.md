# マーケティングメモ：おみくじに学ぶ「売れる構造」

オーナーが「先輩に教わった」として共有してくれた考え方。原文の要点と、メンタルジムへの活かし方をまとめる。
※金額・人数は原文の試算のまま（未検証）。そのまま引用・発信するときは「〜と言われる」「仮に〜とすると」など断定を避ける。

## 原文の要点

- **数字の構造**：原価1枚5〜10円、販売300〜500円で粗利率90%超。広告費・人件費・在庫リスク・クレームがほぼない。
  初詣参拝者は約9,000万人。3人に1人が300円引くと仮定すると、9,000万 × 33% × 300円 ＝ 約900億円。
- **本質は占いではなく「肯定」**：人は未来を知りたいのではなく「今の自分は間違っていない」と肯定されたい。
  書かれているのは「努力せよ・焦るな・縁を大切に・口を慎め」など、誰にも当てはまり否定しづらい言葉＝反証不能コンテンツ。
- **権威とブランド**：構造は情報商材・コンサル・診断・自己啓発・SNS占いと同じ。違いは神社の権威と数百年のブランド。「広告ではなく信用で勝っている」。
- **リピート設計**：去年の内容を誰も覚えていないから毎年買われる。解約率0%・更新手続き不要・価格競争なし。
- **不安との距離**：保険、転職、美容医療、婚活、教育など、売れるビジネスほど人の不安に近い。
- **断言しない**：「これが唯一の正解」と言った瞬間、外れたときのクレームを全部背負う。おみくじは解釈の余白を渡す。
  売れるマーケの本質は「答えを与えること」ではなく「納得できる言葉を用意して、選ばせること」。
- **問い**：誰のどの不安を、どこまで言語化するのか。どこから先を「あなた次第」にするのか。

## メンタルジムへの活かし方（Claudeが提案に使う観点）

メンタルジムのコンセプトは「自分の中に安心を育てる」。おみくじの構造は、**不安をあおるためではなく、安心を届けるため**に使う。

1. **不安を正確に言語化する**：「誰の・どの不安か」を具体的に書く（例：「休日なのに頭が仕事から離れない人」）。読み手が「これ私のことだ」と思えると、「興味なし」を押されにくくなり、読まれる時間も長くなる（X投稿ガイドとも一致）。
2. **まず肯定する**：「あなたは間違っていない」「そう感じるのは自然なこと」から入る。おみくじの本質＝肯定を、誠実な形で提供する。
3. **断言しない・余白を渡す**：「これで必ず治る」ではなく「こんな考え方もある」「今日できそうなものを1つ選んでみて」。押しつけないから外れても角が立たず、選んだ本人の納得感が残る。メンタル分野は効果の断定が誇大表現・トラブルにつながりやすいので、この姿勢はリスク対策にもなる。
4. **「あなた次第」の線引きを設計する**：どこまでを提供側が言葉にし、どこからを本人の選択に委ねるかを、コンテンツごとに意識する。
5. **繰り返したくなる仕組み**：おみくじのような短い「今日のひとこと」「季節ごとのセルフチェック」など、気軽に何度も触れられる形にする（例：年始・年度替わり・連休明けなど、心が揺れやすい時期に合わせる）。
6. **権威より信用を積む**：大きな広告より、毎回の発信で「この人の言葉は安心できる」という信用を少しずつ積み上げる。

## 使わない部分（ブランドを守るために）

- 「不安につけ込む」「不安をあおって買わせる」発想は使わない。メンタルを扱うサービスでは、信用を一気に失う原因になる。
- 「反証不能だからクレームが来ない」という狙いで、中身のない言葉を並べない。余白は**本人が選べるようにするため**に渡すもの。
- 「綺麗事では数字は伸びない」といった強い言い切りや、他業種を下げる表現は、そのまま発信に使わない（X投稿ガイドの「暴言」「興味なし」リスクにもなる）。
