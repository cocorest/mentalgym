# note記事（毎日1本）

個人版メンタルジムの note 連載用の原稿です。`dayNN.md` が 1 日分の記事で、先頭の frontmatter に投稿予定日・タイトル・概要・タグがあります。

- 管理ページ: https://claude.ai/artifact/PtKhv6LJ4ZVvdRW6DYej49 （一覧・全文・コピー・投稿済みチェック）
- 管理ページのソース: `note-admin/index.html`
- 記事を追加・修正したら `python3 note-admin/build.py` で `note-admin/articles.json` を作り直す

## 有料記事

- `note-paid/paid01.md`：980円の有料ワークブック（約1.7万字・ワーク11個・30日プログラム・参考文献つき）
- 本文中の `===有料ライン===` が note の有料エリアの境目。管理ページでは「無料部分」「有料部分」を別々にコピーできる
