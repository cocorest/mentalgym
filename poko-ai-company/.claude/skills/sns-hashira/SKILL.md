# 発信の土台づくり 🏠

発信を「家」にたとえて、土台・柱・入り口を決めます。

## 手順
1. **土台（だれに）**：届けたい人を1人に決める。年齢、悩み、よく見るSNS、その人がつい検索する言葉を聞く。
2. **柱（なにを）**：発信のテーマを3本決める。おすすめの組み合わせ：
   - 🧠 **役立つ柱**：ノウハウ、やり方、まとめ
   - 💛 **共感の柱**：社長の体験、失敗、気持ち
   - 🎁 **信頼の柱**：お客さんの声、実績、裏側
   それぞれの柱に、投稿テーマの例を5つずつ出す。
3. **入り口（どこへ）**：投稿を見た人に、次にどこへ来てほしいか（プロフィール → LINE → 個別相談 など）を1本の線で書く。
4. **ペース**：無理なく続けられる投稿回数を聞いて決める。
5. まとめを見せ、OKをもらって `わたしのこと/発信の土台.md` に保存する。

## 注意
- 社長がいま使っているSNSを優先する。新しいSNSを増やす提案は慎重にする。
