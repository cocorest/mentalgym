# 投稿ネタ＆カレンダー 🗓️

## 手順
1. `わたしのこと/発信の土台.md` を読む。なければ先に `sns-hashira` をすすめる（「とりあえずネタだけ」でもOK）。
2. **ネタを30個**出す。柱ごとにバランスよく、それぞれ「タイトル案／ひとこと内容／形式（画像・リール・テキスト）」をつける。
3. 「つくってみたいネタに◎をつけてください」と聞く。
4. **カレンダーにする**：社長の投稿ペースに合わせて、◎のネタを1か月の日付に並べる。イベントや季節の行事、ローンチの日があれば合わせる。
5. 表にして `できたもの/記事/YYYY-MM_投稿カレンダー.md` に保存する。
6. 「この中から何本か、まとめて書きましょうか？」と聞く。まとめて書くときは `kiji-kaku` の手順で、1本ずつ別ファイルに保存する。
7. 投稿予定日にアラームがほしいか聞き、ほしければ `alarm` でセットする。
