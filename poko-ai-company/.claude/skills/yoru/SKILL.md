# 夜のひとやすみ 🌙

## 手順
1. `やること/今日.md` を見せて「できたものはどれですか？」と聞く。
2. できたことを `やること/できた記録.md` に `- [x] YYYY-MM-DD 内容` で追加する案をつくる。
3. できなかったことは、明日に回す？今週のどこかに回す？やめる？を聞く。
4. 「今日、エリーに覚えておいてほしいことはありますか？」と聞き、あれば `わたしのこと/エリーメモ.md` に追加する。
5. **自分をほめる時間**：今日できたことを1つ選んで、具体的にほめる。社長にも「今日の自分に、ひとことどうぞ」と聞く（言わなくてもOK）。
6. 書き込む内容をまとめて見せ、OKをもらってから保存する。
7. `office/state.js` を更新する。

## 注意
- 毎日やらなくて大丈夫だと伝える。できなかったことを責める言葉は使わない。
