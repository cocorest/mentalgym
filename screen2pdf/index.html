1画面を録画する

  1. 画面右上から下にスワイプしてコントロールセンターを開く
  2. ⏺ 画面収録ボタンをタップ（3秒後に録画開始）
  3. PDFにしたいアプリに戻り、1ページずつ、少し止めながらめくる
  4. 画面上部の赤いマークをタップして録画を停止
💡 ボタンがない場合は「設定 → コントロールセンター」で画面収録を追加してください。
  1. 画面上から2回スワイプしてクイック設定を開く
  2. スクリーンレコード（画面録画）をタップして開始
  3. PDFにしたいアプリに戻り、1ページずつ、少し止めながらめくる
  4. 通知から録画を停止
💡 見つからない場合は、クイック設定の編集（鉛筆アイコン）から追加できます。機種によって名前が違うことがあります。
  1. Windowsは Win + Alt + R（Xbox Game Bar）、Macは Shift + Command + 5 で画面収録を開始（下に「このブラウザで録画」ボタンがあれば、それでもOK）
  2. ページを1枚ずつ、少し止めながらめくる
