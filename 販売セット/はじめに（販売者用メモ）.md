# 販売セット

note などで販売するときに使うファイルを、ここにまとめています。

| ファイル | 中身 | どこで使う？ |
|---|---|---|
| `AIカンパニー_キット.zip` | キット本体（説明書PDFも中に入っています） | 有料部分：ダウンロードリンクで渡す |
| `AIカンパニー_はじめかたガイド.pdf` | 説明書（全10ページ） | 有料部分で渡す／表紙などを無料部分に画像で載せる |
| `AIカンパニー_はじめかたガイド.mp4` | 購入者向けの説明動画（横型・約2分30秒） | 有料部分：YouTube 限定公開などのリンクで渡す |
| `AIカンパニー_販促動画_縦.mp4` | 宣伝用の動画（縦型・43秒） | リール・TikTok・ショート、note の無料部分 |
| `動画台本・投稿文.md` | ナレーション原稿と投稿文の例 | 声やBGMを入れるとき、SNSに投稿するとき |

動画には音が入っていません。CapCut や Canva で、BGMと声を足すのがおすすめです。
