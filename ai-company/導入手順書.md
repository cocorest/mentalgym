# 導入手順書

所要時間：30分くらい（初期設定こみ）

> 📝 画面の名前やボタンの位置は、Claude のアップデートで変わることがあります。
> 見つからないときは、Claude に画面のスクリーンショットを見せて「〇〇はどこ？」と聞いてください。

## 用意するもの
- パソコン（Mac または Windows）
- Claude の有料プラン（Pro 以上）
- このキットのZIPファイル

## いらないもの
- ❌ ターミナル（黒い画面）での操作
- ❌ GitHub の登録
- ❌ プログラミングの知識

Claude のデスクトップアプリに必要なものが全部入っているので、アプリを入れるだけで使えます。

## STEP 1　Claude デスクトップアプリを入れる
1. Claude の公式サイト（claude.ai）から、デスクトップアプリをダウンロードしてインストールします。
2. アプリを開いて、ご自身のアカウントでログインします。

## STEP 2　AIカンパニーのフォルダを置く
1. ZIPファイルを右クリック →「すべて展開」（Mac はダブルクリック）。
2. できた `ai-company` フォルダを、わかりやすい場所（「書類」など）に移します。
   ※ デスクトップやダウンロードに置きっぱなしにすると、うっかり消してしまうことがあります。

## STEP 3　Claude でフォルダを開く
1. Claude アプリの画面上のまん中にある **Code（コード）** タブを押します。
   ※「アップグレード」と出たら、有料プランへの登録が必要です。
2. 実行場所は **Local（ローカル）** を選びます。
3. **Select folder（フォルダを選択）** を押して、`ai-company` フォルダを選びます（中のファイルではなく、フォルダごと）。

## STEP 4　話しかける
1. 「はじめまして」と送ります。
2. 秘書のエリーが質問するので、答えていきます（10分くらい）。
3. 最後に「メニュー」が出たら準備完了です 🎉

## STEP 5（おすすめ）メール・カレンダー連携
メールチェックやアラームをもっと便利に使うための設定です。
1. 文字を入力する欄の横にある **＋** ボタンを押して、**Connectors（コネクタ）** を選びます。
2. **Gmail** と **Google カレンダー** を選んで、画面の案内どおりにGoogleアカウントで許可します。
3. エリーに「メールをチェックして」と話しかけて、動くか試します。

※ 連携しなくても、アラームは「カレンダーに追加できるファイル」で使えます。

## 引っかかったときの聞き方 🆘
わからないことは、**Claude にそのまま聞く**のがいちばん早いです。専門用語がわからなくても大丈夫。

### スクショで聞く（おすすめ）
1. 困っている画面のスクリーンショットを撮ります。
   - Mac：`Shift` + `Command` + `4` で範囲を選ぶ（画面全体なら `Shift` + `Command` + `3`）
   - Windows：`Windows` + `Shift` + `S` で範囲を選ぶ
2. Claude の入力欄に貼りつけます（Mac は `Command` + `V`、Windows は `Ctrl` + `V`）。画像をドラッグして入力欄に落としても、入力欄の横のボタンから添付してもOKです。
3. ひとこと添えて送ります。

### 文章で聞く
次の3つを書くと、答えが早く正確になります。
```
・やろうとしたこと：〇〇をしようとした
・起きたこと：△△と表示された／何も起きない
・どうしたいか：□□できるようにしたい
```
例：「オフィス画面を開こうとして index.html をダブルクリックしたら、真っ白な画面になりました。どうしたら表示できますか？」

### どこで聞く？
- **ふだんの困りごと**：AIカンパニーを開いている Code タブで、そのままエリーに聞く
- **Code タブ自体が開けない・動かない**：Claude アプリの **Chat（チャット）** タブで、スクショを貼って聞く
- **それでも解決しないとき**：購入者サポートへ（連絡先は `ご利用規約.md` の最後）

## よくある質問
**Q. 「許可しますか？」と聞かれた**
A. エリーがファイルを保存したり、ツールを使ったりするときの確認です。内容を見て、問題なければ許可してください。

**Q. 「Git is required（Gitが必要です）」と表示された（主に Windows）**
A. まず Claude アプリを最新版に更新してください（Windows は「Help」→「Check for Updates」、Mac は「Claude」→「Check for Updates」）。古いバージョンだけで出る表示です。更新しても出る場合は、公式サイト（git-scm.com）から「Git for Windows」をインストールしてから、もう一度開いてください。

**Q. ターミナルや GitHub の登録は必要？**
A. 必要ありません。AIカンパニーは、パソコンの中のフォルダだけで動きます。

**Q. エリーが設定を忘れたみたい**
A. 「わたしのこと を読み直して」と伝えてください。

**Q. 間違えて大事なファイルを消してしまった**
A. 買ったときのZIPから、もう一度展開すれば元に戻せます（`わたしのこと/` と `できたもの/` は、ときどきバックアップしておくと安心です）。
