# AIカンパニーへようこそ 🎉

このフォルダが、あなた専用の「AIの会社」です。
Claude（クロード）でこのフォルダを開いて話しかけるだけで、秘書の「エリー」とAI社員たちが働きはじめます。

## まずやること
1. `はじめかたガイド.pdf`（イラストつきの説明書）を見ながら、Claude でこのフォルダを開く
2. 「はじめまして」と送る
3. エリーの質問に答えて、初期設定をする（10分くらい）

## そのあとは
「メニュー」と送れば、いつでも今できることが表示されます。
こんなふうに、ふだんの言葉で頼んでOKです。

- 「来月のイベントの告知記事を書いて」
- 「今日のメールをチェックして、返信が必要なものを教えて」
- 「田中さんに 15,000円 の領収書をつくって」
- 「明日の朝9時にZoomのリマインダーをセットして」
- 「お客さんの予約を管理できるアプリをつくって」
- 「毎週やってる売上集計を自動化したい」
- 「おはよう！」（朝のエリー便：気分・予定・今日やることを一緒に決めます）
- 「投稿ネタを30個考えて」
- 「新しい講座をつくりたい」

## オフィス画面
`office` フォルダの `index.html` をダブルクリックすると、AI社員たちが働くオフィスが見られます。
「オフィスを開いて」と頼んでもOKです。

## フォルダの中身
| フォルダ | 入っているもの |
|---|---|
| `わたしのこと/` | あなたの情報（AIが毎回読みます） |
| `できたもの/` | AIが作ったものの保存先 |
| `ひながた/` | 領収書などの型 |
| `台帳/` | 領収書の発行記録など |
| `やること/` | 今日・今週のやること、できた記録 |
| `office/` | オフィス画面 |

困ったら、エリーに「困った」とそのまま話しかけてください。
