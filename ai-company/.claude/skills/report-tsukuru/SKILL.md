# レポートをまとめる

## 手順
1. 確認すること（1つずつ）
   - 誰が読む？（自分用／お客さん／チーム）
   - 何のレポート？（売上、ふり返り、調査、議事録 など）
   - 材料はある？（数字、メモ、ファイル、録音の文字起こし など）
2. 材料を読み込む。数字は表にまとめ、計算した値は式も残す。
3. 次の型でまとめる。
   ```
   # タイトル
   ## ひとことで言うと（3行）
   ## くわしい内容（表・グラフ）
   ## わかったこと
   ## 次にやること
   ```
4. お客さんに渡すものなら、ていねいな言葉に整える。
5. `できたもの/レポート/YYYY-MM-DD_タイトル.md` に保存する。印刷・PDFにしたい場合は、同じ内容でHTMLもつくり「ブラウザで開いて『印刷』→『PDFに保存』」と案内する。

## 注意
- 材料にない数字はつくらない。足りない数字は「ここは数字が必要です」と書いて社長に聞く。
