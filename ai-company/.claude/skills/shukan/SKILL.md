# 週のふり返りと計画 📅

## はじめに判断すること
- `やること/今週.md` が空、または週のはじめ → **計画だけ**つくる
- 今週のやることがあり、週の終わり、または「ふり返り」と言われた → **ふり返り＋来週の計画**
- わからなければ「計画をつくる？ふり返りをする？」と聞く

## 計画をつくる
1. `わたしのこと/目標.md` の今月の目標を読む（空なら、先に今月の目標を1つ聞く）。
2. 今週の使える時間と、決まっている予定を聞く（カレンダーがつながっていれば読む）。
3. 今週やることを3〜7個、大事な順に提案する。
4. OKをもらって `やること/今週.md` に保存する。

## ふり返り＋来週の計画
1. `やること/今週.md` と `やること/できた記録.md` を見比べて、できた／できなかったに分ける。
2. できなかった理由を一言ずつ（時間が足りない、後回しにした、むずかしかった など）。
3. 「今週いちばんうれしかったこと」を聞く。売上や数字だけで評価しない。
4. 来週いちばん大事なことを1〜3個決める。
5. `わたしのこと/目標.md` の「いま進めていること」を更新する。
6. まとめを見せ、OKをもらって保存する。`office/state.js` も更新する。
