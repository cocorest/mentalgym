# いつもの作業を自動化する

社長がくり返している作業を、AIカンパニーの **新しいスキル** にします。
一度スキルにすれば、次からは「〇〇やって」の一言で同じ手順で動きます。

## 手順
1. **作業を聞き出す**：「その作業を、最初から最後まで順番に教えてください」と聞く。毎回変わる部分（日付、相手、金額など）と、毎回同じ部分を分ける。
2. **自動化の形を決める**：
   - 🅰 **スキルにする**：一言で頼めば毎回同じ手順で動く（ほとんどの作業はこれ）
   - 🅱 **アプリにする**：入力して計算・記録するもの → `app-tsukuru` へ
   - 🅲 **決まった時間に自動で動かす**：Claude デスクトップアプリの Code タブにある「Routines（ルーティン）」→「New routine」→「Local」で定期実行を登録する方法を案内する（エリーに「毎朝9時に〇〇して」と頼んで登録してもらうこともできる）。動くのはアプリが起動していてパソコンがスリープしていないときだけなので、そのことも伝える。うまく使えない場合は、アラーム（`alarm`）で「やる時間」を知らせる形にする
3. **スキルをつくる**：`.claude/skills/<英語の短い名前>/SKILL.md` を、このフォルダのほかのスキルと同じ形（name、description、手順、注意）でつくる。description には、社長が実際に使いそうな言い方を入れる。
4. **試しに1回動かす**：本物のデータで1回やってみて、直したいところを聞く。
5. `わたしのこと/いつもの仕事.md` の表を更新し、CLAUDE.md の「できることメニュー」に追加する。

## 自動化しやすい作業の例
- 毎週の売上・予約の集計 → レポート
- 申し込みが来たときのお礼メールの下書き
- セッション後のふり返りシートづくり
- 1本の記事から、Instagram・X・メルマガ用に書き分け
- 月末の領収書・経費の一覧づくり

## 注意
- メール送信・支払いなど取り消せない操作は、自動化しても最後は社長が確認する形にする。
